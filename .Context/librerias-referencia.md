# Librerías de Referencia — midudev picks

| # | Nombre | Funcionalidad | Descripción |
|---|---|---|---|
| 1 | **Wouter** | Router | Enrutamiento para React. Alternativa ligera a React Router. API casi idéntica pero pesa ~2KB. |
| 2 | **Shadcn UI** | Componentes UI | No es una librería instalable, son componentes que copiás a tu proyecto. Personalizables, accesibles, basados en Radix UI + Tailwind. |
| 3 | **TailwindCSS** | Estilos | Framework CSS basado en clases de utilidad. Sin CSS custom, todo inline en el HTML. |
| 4 | **Tailwind CSS Animated** | Animaciones CSS | Plugin de Tailwind que agrega clases de animación listas para usar. |
| 5 | **Motion** | Animaciones JS | Librería de animaciones para React (ex Framer Motion). Declarativa, potente, con gestos y transiciones. |
| 6 | **Zustand** | Estado global | State management minimalista. Sin boilerplate, sin providers, una función y listo. |
| 7 | **Tanstack Query** | Data Fetching | Manejo de server state: fetch, caché, refetch, loading/error states. |
| 8 | **Sonner** | Notificaciones | Toast notifications. Un componente, una función, listo. Minimalista y bonito. |
| 9 | **React Hot Toast** | Notificaciones | Alternativa a Sonner. Toasts personalizables con promesas. |
| 10 | **Toastify** | Notificaciones | Toast para JS vanilla, sin dependencia de framework. |
| 11 | **Conform** | Formularios | Validación de formularios para React (2025). Compatible con Zod y servidores. |
| 12 | **React Hook Form** | Formularios | Alternativa a Conform. Sin re-renders, integración fácil con Zod. |
| 13 | **Better Auth** | Autenticación | Librería de auth moderna para 2025. Framework-agnostic, fácil de configurar. |
| 14 | **Auth.js** | Autenticación | Antes NextAuth. Auth para Next.js con OAuth, credenciales, JWT. |
| 15 | **Nivo** | Gráficas | Gráficas para React basadas en D3. Rica en tipos de chart, responsive. |
| 16 | **Recharts** | Gráficas | Alternativa a Nivo. Componentes de gráficas declarativos para React. |
| 17 | **Tremor** | Dashboards | 24 componentes para dashboards (gráficas + tablas). Tailwind, open source. |
| 18 | **DnDKit** | Drag & Drop | Kit modular para drag & drop en React. Accesible, extensible. |
| 19 | **@formkit/drag-and-drop** | Drag & Drop | 4KB, sin dependencias. Funciona en React, Vue y JS vanilla. Con animaciones. |
| 20 | **React PDF** | Documentos | Renderizar y generar PDFs dentro de React. |
| 21 | **React Window** | Performance | Virtualización de listas largas. Solo renderiza lo que está visible en pantalla. |
| 22 | **FilePond** | Uploads | Drag & drop para subida de archivos/imágenes. Funciona en React, Vue y Angular. |
| 23 | **Swiper** | Sliders | Slider/carrusel touch-friendly. Mobile first, muy customizable. |
| 24 | **Floating UI** | Posicionamiento | Posicionar elementos flotantes: tooltips, popovers, dropdowns. Preciso y accesible. |
| 25 | **Atropos** | Efectos visuales | Efecto tilt 3D interactivo. Para cards o secciones hero. |
| 26 | **React Three Fiber** | 3D | Three.js declarativo para React. Para experiencias 3D en el browser. |
| 27 | **Tabler Icons** | Iconos | Set de +5000 iconos SVG. Open source, consistentes, en React o SVG puro. |
| 28 | **react-icons** | Iconos | Mega colección de iconos (Font Awesome, Material, etc.) en un solo paquete React. |
| 29 | **UseAnimations** | Iconos animados | Iconos con micro-animaciones (lottie). Para estados: loading, like, check, etc. |
| 30 | **Tempo** | Fechas | Librería moderna para fechas en JS. 5KB, buena API, multi-timezone. |
| 31 | **date-fns** | Fechas | Funcional y modular. Solo importás las funciones que usás. |
| 32 | **day.js** | Fechas | API idéntica a Moment pero en 2KB. |
| 33 | **Luxon** | Fechas | De los creadores de Moment. Más moderna, soporta Intl nativo. |
| 34 | **react-i18next** | Internacionalización | i18n para React. Traducciones, plurales, interpolación. |
| 35 | **nuqs** | Estado en URL | Sincroniza el estado de React con los query params de la URL. |
| 36 | **React Day Picker** | Fechas UI | Componente de calendario para selección de fechas. Navegable, personalizable. |
| 37 | **Animista** | Animaciones CSS | Generador visual de animaciones CSS. Copiás el CSS que necesitás. |
| 38 | **Animate.css** | Animaciones CSS | La más popular. Clases CSS de animación listas para usar. |
| 39 | **Hover.css** | Animaciones CSS | Animaciones CSS que se activan al hacer hover. Para botones y cards. |
| 40 | **Cattocss** | Animaciones CSS | Colección de animaciones CSS, alternativa a Animate.css. |
| 41 | **Animatopy** | Animaciones CSS | Alternativa ligera a Animate.css. |
| 42 | **Vitest** | Testing | Test runner moderno, compatible con Vite. Rápido, API similar a Jest. |
| 43 | **testing-library** | Testing | Testear componentes React desde la perspectiva del usuario. |
