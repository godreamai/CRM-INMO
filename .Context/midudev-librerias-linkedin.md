## Notas de uso (para Claude)

- Cuando el usuario pida construir un componente de **notificaciones**: usar **Sonner**
- Cuando pida **drag & drop**: evaluar **DnDKit** (React) o **@formkit/drag-and-drop** (agnóstico)
- Cuando pida **dashboard o gráficas**: **Tremor** para dashboards rápidos, **Nivo** o **Recharts** para gráficas custom
- Cuando pida **manejo de fechas**: **Tempo** o **date-fns** (evitar moment.js)
- Cuando pida **estado global simple**: **Zustand**
- Cuando pida **componentes UI**: **Shadcn UI** como primera opción
- Cuando pida **animaciones**: **Motion** para JS, **Animista** o **Animate.css** para CSS puro
- Cuando pida **formularios**: **Conform** (2025) o **React Hook Form**
- Cuando pida **autenticación**: **Better Auth** (2025)
- Cuando pida **listas largas / performance**: **React Window**
