## Estructura semanal tipo

| Día | Feed Instagram | LinkedIn | Stories |
|---|---|---|---|
| Lunes | Reel — DOLOR | — | 5-6 stories: contexto + dolor + encuesta |
| Martes | Reel — DOLOR o TRANSFORMACIÓN | Post autoridad | 5-6 stories: mockup/demo + pregunta + CTA |
| Miércoles | Carrusel — AUTORIDAD o TRANSFORMACIÓN | — | 5-6 stories: compartir carrusel + encuesta + insight |
| Jueves | Reel — DEMO / SISTEMA | Post autoridad | 5-6 stories: detrás de escena + demo visual + CTA |
| Viernes | Reel — OBJECIÓN | — | 4-5 stories: objeción + respuesta + CTA |
| Sábado | Carrusel — CHECKLIST o ANTES/DESPUÉS | — | 4-5 stories: humanizar + proceso + CTA suave |
| Domingo | Descanso o Reel extra si hay energía | — | Opcional |

---

## Objetivo por día

- **Lunes:** abrir la semana con una verdad incómoda. El dueño se reconoce.
- **Martes:** mostrar el contraste. Así es el caos, así es con el sistema.
- **Miércoles:** educar. Construir autoridad sin vender directo.
- **Jueves:** mostrar el producto. Demo, pantallas, cómo funciona de verdad.
- **Viernes:** demoler objeciones. "Es caro", "soy chico", "ya tengo Excel".
- **Sábado:** humanizar. Fundador, proceso, historia detrás de GDAI.

## Estructura de cada formato

### REEL — Fórmula base

```
[0-2 seg]   HOOK — La frase más fuerte. Que duela o sorprenda.
[2-20 seg]  DESARROLLO — Una sola idea. Sin tecnicismos. Máximo 3 puntos.
[20-30 seg] CTA — Directo. "Comentá DEMO."
```

Niveles de detalle que genera la skill para Reels:
- Guión línea por línea (listo para grabar)
- Descripción visual / referencias de qué mostrar en pantalla
- Prompt para generación de imagen o video con IA
- Caption completo con hashtags

### CARRUSEL — Estructura

```
Slide 1     → Título que genera dolor o curiosidad. Sin explicar nada.
Slides 2-5  → Una idea por slide. Pocas palabras. Que se lea de un vistazo.
Slide final → CTA. "Comentá DEMO" o pregunta para comentarios.
```

Niveles de detalle que genera la skill para Carruseles:
- Texto de cada slide
- Descripción visual de cada slide
- Caption con hashtags

### STORIES — Estructura de secuencia

```
Story 1-2   → Contexto / apertura del tema del día
Story 3     → Pregunta, encuesta o dolor puntual
Story 4-5   → Insight, mini demo o transformación
Story 6     → CTA o link a post del feed
```

Niveles de detalle que genera la skill para Stories:
- Texto de cada historia en secuencia
- Tipo de recurso (encuesta, caja de preguntas, texto, imagen)
- Tono y énfasis visual

### LINKEDIN — Estructura

```
Línea 1     → Hook (única línea visible antes de "ver más")
[espacio]
Párrafo 1   → Desarrollar el problema o insight
Párrafo 2   → Profundizar o dar vuelta la idea
Párrafo 3   → Mostrar la solución o reflexión
[espacio]
Cierre      → Pregunta para comentarios o reflexión final
CTA         → Sutil. No siempre "Comentá DEMO". A veces solo una pregunta.
```

## Dolores por pilar — banco de temas

### DOLOR (usar como disparadores de ideas)
- Leads que entran y no se responden a tiempo
- Vendedores que atienden desde el celular personal
- El dueño no sabe cuántos leads perdió esta semana
- Dos brokers contactan al mismo cliente sin saberlo
- El cliente que no respondiste en 5 minutos ya llamó a la competencia
- No saben qué canal de publicidad genera más consultas
- "Llamar mañana" en un post-it que nunca se cumple
- El vendedor estrella que se va y se lleva los contactos
- 200 mensajes de WhatsApp sin ningún orden
- Domingo a la noche: el cliente escribe, nadie responde

### TRANSFORMACIÓN (mostrar el después)
- El sistema responde en segundos, el broker llama cuando el lead ya está calificado
- El dueño ve en tiempo real cuántos leads entraron, cuántos se contactaron, cuántos cerraron
- Cada consulta tiene un estado: nuevo, contactado, interesado, visita agendada, cerrado
- El broker sabe exactamente a quién llamar hoy y por qué
- Cuando el vendedor se va, los contactos quedan en el sistema
- Propiedad nueva → el sistema avisa automáticamente a los interesados que encajan
- Seguimiento post-visita automático: 24hs después el cliente recibe un mensaje

### AUTORIDAD (posicionar como expertos)
- Por qué las inmobiliarias pierden leads aunque tengan muchas consultas
- La diferencia entre tener WhatsApp y tener un sistema de ventas por WhatsApp
- 3 errores de seguimiento que tienen casi todas las inmobiliarias
- Qué debería ver el dueño de una inmobiliaria cada mañana
- Por qué el Excel no alcanza cuando el negocio empieza a crecer
- Checklist: 7 cosas que debería saber el dueño de una inmobiliaria cada semana

### OBJECIÓN (desmontarlas)
- "Mi inmobiliaria es chica, no necesito esto"
- "Mis vendedores ya usan WhatsApp"
- "Ya tengo Excel"
- "No quiero obligarlos a cargar datos"
- "No tengo tantos leads"
- "No quiero pagar por otro software"
- "Es complicado de usar"

## Métricas que importan (para orientar la estrategia)

No mirar solo views. Las métricas que importan para GDAI:

| Métrica | Qué indica |
|---|---|
| Comentarios "DEMO" | Intención directa |
| DMs recibidos | Oportunidad comercial real |
| Respuestas a Stories | Relación con audiencia |
| Guardados | Valor educativo del contenido |
| Compartidos | El dolor resonó |
| Demos agendadas | Conversión final |

**Métrica madre:** cantidad de conversaciones reales generadas por semana.

## Qué nunca publicar

- Contenido genérico sin relación al nicho inmobiliario
- Celebraciones de días internacionales sin conexión a la propuesta de valor
- Tecnicismos de software sin contexto (API, webhook, n8n, etc.)
- "IA" como argumento de venta o como hype futurista
- Frases motivacionales sin conexión con el dolor del cliente
- El precio en público
- Contenido de relleno solo para "estar activos"
